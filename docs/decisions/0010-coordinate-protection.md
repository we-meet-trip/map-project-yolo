# 0010. 기기 좌표는 암호 봉투 대신 로그 가림과 정밀도 낮추기로 보호한다

- 상태: 채택

## 맥락
사진 식별과 장소 검색에 기기 위치를 쓴다. 다른 서비스 사이에서는 좌표를 암호화한 봉투로 주고받는다. 이 서비스는 앱이 관문을 거쳐 직접 연결하고, 좌표는 앱이 보낸다.

## 선택지
1. 앱과 이 서비스 사이에도 좌표 봉투를 쓴다.
2. 전송 구간은 TLS 에 맡기고, 이 서비스 안에서 로그 가림과 외부 전송 정밀도 낮추기로 보호한다.

## 결정
2번. 앱에서 봉투를 만들려면 공개 앱에 대칭 열쇠를 넣어야 하는데, 누구나 꺼낼 수 있어 보호 효과가 없다. 대신 로그로 나가는 길목에서 좌표를 가리고, Gemini 프롬프트에는 주소나 소수 셋째 자리(약 100m)로 줄인 좌표만 넣는다. 위치는 사용자가 위치 공유에 동의했을 때만 쓴다.

## 결과
- 로그와 외부 모델 프롬프트에 정밀한 기기 좌표가 남지 않는다.
- Kakao 역지오코딩과 장소 검색에는 장소를 찾기 위해 원래 좌표를 보낸다([data.md](../data.md)).
