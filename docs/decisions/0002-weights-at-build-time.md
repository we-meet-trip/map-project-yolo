# 0002. 가중치는 저장소에 넣지 않고 빌드 때 받아 해시로 고정한다

- 상태: 채택

## 맥락
YOLO11n 가중치와 ultralytics 패키지는 AGPL-3.0(가중치는 상용 라이선스도 있음)이다. 이 저장소의 코드는 MIT 다. 컨테이너는 기동할 때 네트워크나 쓰기 권한 없이 뜰 수 있어야 한다.

## 선택지
1. 가중치 파일을 저장소에 커밋한다.
2. 기동할 때 ultralytics 의 자동 내려받기에 맡긴다.
3. 이미지 빌드 때 고정한 공식 릴리스 주소에서 받아 sha256 으로 확인하고 이미지에 넣는다.

## 결정
3번. Dockerfile 이 `ADD --checksum=sha256:…` 로 공식 릴리스 자산을 받는다. 해시가 다르면 빌드가 멈춘다. 이름 기반 자동 내려받기는 경로 접두사가 붙으면 동작이 달라지고 해시를 확인하지 않아서 쓰지 않는다.

## 결과
- 저장소에는 AGPL 자산이 없다. 대신 이 저장소로 만든 이미지(결합물)를 배포하거나 네트워크 서비스로 제공하면 AGPL 의무가 따를 수 있어, [NOTICE](../../NOTICE)·README 에 알리고 이미지에도 `LICENSE`·`NOTICE` 를 넣는다.
- 실행 중에는 가중치를 받지 않는다. 다른 가중치는 마운트하고 `YOLO_MODEL_PATH` 로 가리킨다.
- 가중치 판을 올리려면 Dockerfile 의 주소와 해시를 함께 바꾼다.
