# 0001. 식별은 Gemini 가 하고 YOLO 는 힌트로만 쓴다

- 상태: 채택

## 맥락
카메라 화면 속 대상(랜드마크, 음식, 제품 등)의 이름과 설명을 사용자 질문에 맞춰 돌려줘야 한다. YOLO 가 미리 학습한 클래스 이름("person", "cup" 같은 일반 범주)만으로는 "이 건물이 무엇인가" 같은 질문에 답할 수 없다.

## 선택지
1. YOLO 클래스 이름을 검색어로 바로 쓴다.
2. 사진을 Gemini 에 보내 직접 식별하고 YOLO 는 쓰지 않는다.
3. 사진을 Gemini 가 직접 식별하되, YOLO 가 찾은 가장 신뢰도 높은 객체를 힌트로 함께 보낸다.

## 결정
3번. 처음에는 1번으로 시작했고, 2번으로 바꿨다가 3번으로 정착했다. Gemini 에는 사진, 질문, 탐지 힌트("참고용이며 최종 판단은 이미지를 직접 보고"), 위치(동의했을 때만)를 보내고 `{name, category, description, search_query}` JSON 만 받는다.

## 결과
- 식별 품질은 Gemini 판에 달려 있다. YOLO 는 가볍게 CPU 에서 돌고, 응답에 탐지 결과(`detected_object`)를 함께 실어 준다.
- 사진 인식 한 번이 Gemini 호출 한 번이다. 호출량은 사용자의 촬영 횟수와 계정 한도로 제한된다.
