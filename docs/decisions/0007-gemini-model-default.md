# 0007. Gemini 모델 이름은 설정으로 바꾸고, 코드 기본값은 폐기 일정이 없는 판을 쓴다

- 상태: 채택

## 맥락
사진 식별과 텍스트 답변에 Gemini 모델을 쓴다. 공급자는 모델 판을 주기적으로 폐기하고, 같은 판도 계정·환경에 따라 갑자기 부를 수 없게 될 수 있다.

## 선택지
1. 코드에 모델 이름을 고정한다.
2. 설정(`MAP_PROJECT_GEMINI_MODEL`)으로 바꾸고, 코드 기본값은 그때 폐기 일정이 발표되지 않은 판으로 둔다.

## 결정
2번. 기본값은 `gemini-2.0-flash` 에서 `gemini-2.5-flash` 로, 다시 `gemini-3.8-flash` 로 옮겼다. 마지막 변경은 이전 판의 폐기 예정이 알려졌기 때문이다. 모델 이름은 추천 에이전트와 같은 공용 설정을 쓴다. 배포 구성은 `.env` 로 다른 판을 넘길 수 있고, 그 값이 코드 기본값보다 우선한다.

## 결과
- 이미지를 다시 빌드하지 않고 설정만으로 모델을 바꿀 수 있다.
- 모델을 바꾸면 식별 JSON 형식을 지키는지, 이미지 입력을 받는지 다시 확인해야 한다(시험은 모델 대역을 쓰므로 실제 모델의 형식을 보장하지 않는다).
