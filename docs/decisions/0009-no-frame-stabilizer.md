# 0009. 여러 프레임을 모아 판정하는 안정화 필터를 두지 않는다

- 상태: 채택

## 맥락
처음 설계는 카메라 프레임을 계속 받아, 같은 객체가 여러 프레임 연속 탐지될 때만 모델을 부르는 안정화 필터를 두었다. 그런데 앱은 음성 트리거 시점에 사진 한 장만 보낸다(`map_project_yolo/vision/detector.py` 의 모듈 설명).

## 선택지
1. 안정화 필터를 유지한다.
2. 필터와 관련 설정을 지우고, 받은 한 장으로 바로 처리한다.

## 결정
2번. 연속 스트림이 아니므로 필터는 쓰이지 않는 코드였다.

## 결과
- 요청 하나가 추론 한 번, 모델 호출 한 번이다. 호출량은 사용자의 촬영 횟수로 정해진다.
- 앱이 연속 스트림으로 바꾸면 이 결정을 다시 봐야 한다.
